Archive external links

Replaces every external link in the doc with its latest Wayback Machine snapshot. If no snapshot exists, automatically saves one first. 80,000 Hours links are left unchanged.
Heads up: this modifies your doc. Run it once you're done editing — it's not easy to undo individual link rewrites in bulk. (Use the debug panel below to bulk un-archive if needed.)
⚙ Debug
Reverses the archive operation: finds every web.archive.org link in the doc and rewrites it back to its original URL.
